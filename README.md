# freeRTOS_Project
A personal ARM-based embedded systems project created to improve my skills in embedded software development and FreeRTOS.

## Goals
- Learn ARM architecture
- Gain hands-on experience with FreeRTOS
- Practice task scheduling and synchronization
- Develop embedded C programming skills

## Hardware
- STM32F767ZIT6U (MCU)
- Development Board (Nucleo-F767ZI)
- ST-Link programmer

## Software
- STM32CubeIDE
- FreeRTOS
